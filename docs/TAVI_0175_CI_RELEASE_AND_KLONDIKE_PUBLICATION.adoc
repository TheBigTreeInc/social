== Scope and authority

Tavi Social owns the messenger host, Store UI, native release gate and installation approvals. TaviX (separate repository) owns the official aggregate extension index and distributable artifacts. Klondike/game publisher owns its source, license, immutable package content and approval of publication. This document requests owner work; it makes no cross-project source changes.

== Public Klondike distribution — owner request to TaviX

`client/src/extensions/repositories.js` already defaults to `https://thebigtreeinc.github.io/tavix/tavi.repository.json`; `client/src/ui/storefront.js` displays entries classified as public apps/games. Therefore do not hard-code a second Klondike install path in Social.

The *currently accessible* official TaviX repository index contains Atrium and Companion only; no Klondike entry. A local `.tavix` game is not a remote public release. The uploaded Klondike `.tavix` is Library/Project-backed and could not be byte-materialized from this session; no publisher source repository, approved license or hosted artifact has been independently verified.

TaviX/owner must:

. Obtain the reviewed Klondike source and exact release `.tavix` archive; validate archive manifest, `kind=game`/classification, package integrity, allowed resource references and responsive platform list.
. Confirm publisher identity and a real source repository URL, SPDX license policy, ownership and public-publishing authorization; do not invent those values.
. Host the required same-origin static package entrypoint and all hashed resources in the TaviX extension distribution. Publish through existing staged approval, not direct mutation of user installations.
. Add one authenticated, versioned `tavi.repository/v1` entry to the official TaviX index, with exact `manifest`, HTTPS `entrypoint`, browsable HTTPS `source`, `license` and immutable release `revision` metadata. Verify source path ends with the manifest panel path. Do not advertise a URL until it exists and is accessible.
. Test first-time install from clean Windows and Android Tavi clients, isolation/cancel/permission flows, source pinning, offline behavior if advertised, public Games filter and consistent icon/detail page. Existing sideload users must not be silently migrated to another source or publisher.
. If Atrium adds Klondike discovery metadata, prevent duplicate install cards; Atrium owns optional game context, not extension installation.

== Acceptance and evidence

Do not count a source-test PASS as a native or GitHub CI PASS. The release remains blocked while any required workflow lacks a successful exact-SHA result, a signed APK or Windows installer is missing, operator acceptance is absent or the protected publication environment is not approved. Klondike public availability remains blocked until its actual remote catalog and resources are live and first-time install is proven.
