Failed workflow: https://github.com/TheBigTreeInc/social/actions/runs/39318552767 , job 118286294325, step `Verify Social server and client protocols`, one failure out of 155 Node tests. The published bundled Notepad `index.html` is LF text (2226 bytes) and the catalog uses that size plus its SHA-256. `.gitattributes` previously enforced LF only for YAML/AsciiDoc, not HTML. Windows checkout can expand line endings by 10 bytes. Remedy: enforce LF for all SHA-pinned bundled extension text formats; preserve exact catalog size and SHA (never relax verification).
