= Tavi 0.3.124 — local Lucide icon and Home UX foundation
:revdate: 2026-11-05

== Scope and ownership

* Host-only, locally bundled Lucide SVG shapes under `client/src/ui/lucide-icons.js` with a fixed upstream revision and ISC/Feather attribution in `client/src/ui/LUCIDE_LICENSE.txt`. No runtime icon CDN, fonts, SVG downloaded from an extension, or new npm dependency. All existing `uiGlyph`/`appGlyph` names remain supported with a closed alias map and safe puzzle fallback.
* The Tavi bottom tab labeled *Apps* now uses an app grid. The storefront remains reserved for the *App Store* entry. Home, Chats, Games, notifications, settings, wallet, help and launcher icons share Lucide's 24x24 geometry and stroke convention.
* Preserve the existing Home buddy-list primary layout and distinct Chats inbox. Improve Online/Offline group affordances, rectangular touch targets, avatar/Companion placement, less harsh separators, and unread state. The Companion placeholder now shows a paw rather than an unexplained sparkle. If a recent direct message exists, Home can show its summary; actual text is displayed ONLY when the account opted into message previews. Presence remains accessible even when a preview is shown.
* All elements remain host-owned. Existing extension iframe sandbox, Social account/session state, native routing, wallet and game services are unchanged. Theme uses existing light/dark design tokens; reduced-motion and keyboard focus styles remain.

== Automated source checks

* `node --test client/tests/ui-lucide-foundation-124.test.mjs` — five tests: full aliased-icon coverage, static/fail-closed markup, navigation/store distinction, optional preview/privacy and accessible Home states, touch/dark CSS boundaries.
* `npm run verify` — full server/client/OpenClaw regression suite and package checks.
* `npm run extensions:check` and `python tools/generate-looprd.py --check` — no publisher asset or LoopRD descriptor changes.
* ZipRunner post-update test 1 includes the new icon source checks; it still requires local installed-source/Windows acceptance. A source test pass does not establish a visual pass.
