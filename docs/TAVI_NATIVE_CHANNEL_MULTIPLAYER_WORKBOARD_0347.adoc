= Tavi Workboard Plan: Native OpenClaw Channel & Shared Multiplayer

:toc:

== Core architecture

Tavi is the general-purpose Social chat platform; OpenClaw is **one ordinary Tavi account/client**. Windows, Android, Web, other bot frameworks and standalone SDK users all use the same Social identity/messaging contracts. Installing OpenClaw is optional and must not be required on a Tavi server. The native plugin integrates with OpenClaw lifecycle and agent sessions using the public Tavi SDK.

Life exclusively owns match creation, player-seat authorization, game logic and turns. Atrium owns discovery, launch and resume. A successful Tavi challenge acknowledgement is not a playable Life match or automatic seat.

== Milestones

* **Channel ready:** OpenClaw can participate in normal Tavi messaging and respond to Tavi game challenges using the installed native plugin alone, with no external `tavi-openclaw-service.mjs` process. This proves messaging, not game play.
* **Life opponent ready:** The authoritative Life backend creates a match, validates two Tavi seats, and accepts OpenClaw turns through its own game API.
* **Shared multiplayer accepted:** A user launches from Tavi/Atrium, challenges OpenClaw, plays a complete match, resumes on another device and passes access-control/restart tests. This requires operator sign-off.
