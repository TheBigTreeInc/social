= Tavi 0.3.55 — Classic roster Home restoration
:toc:

== Design decision

The operator approved the v0.3.54 raised circular bottom Games / Main menu / Messages dock, but prefers the earlier MSN/Yahoo Messenger/Xfire-style information density above it. Keep the old proven contact roster component instead of replacing it with modern oversized summary cards. Client-side only.

== Home

* Classic File, Contacts, Actions, Tools, Help menu bar (native titlebar is provided by Windows).
* Own portrait, username, presence, account reference and connected server identity.
* Existing compact actions: Add, Chat, Picture, Games, Pet, Inbox and Sync.
* Contact search; Community Lobby and recent conversations; collapsible Online, Offline, Requests, and Pending groups; unread badges.
* Minimized game/chat activity chips with explicit resume actions, inside the roster.
* My Games with monitored turn alerts and quick actions; bottom connection status.
* Forest green / mint / cream palette, without changing source data or underlying authorization rules.
* Preserve v0.3.54 raised round Main menu between small Games and Messages controls, **only on Home**.

== Focused content

Conversation and embedded game surfaces are separate; the global three-icon Home footer does not render there. Windows secondary native chat/game windows remain brokered through the authenticated main window. Only supported embedded games are minimizable; an external browser remains external.
