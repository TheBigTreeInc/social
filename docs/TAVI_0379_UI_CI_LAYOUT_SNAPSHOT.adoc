== Source-only changes

`client/tools/ui-qa-touch.mjs` introduces a browser-safe atomic DOM snapshot of the primary roster section button and all buddy rows. If any required element has no non-zero rectangle, is detached or not visible, it returns null to request a retry. It always returns real positive heights, even when below the required threshold.

`client/tools/ui-qa.mjs` uses Playwright's animation-frame `waitForFunction` before assertions, then checks >=44px for each visible buddy and the section header. The failure now includes measured heights and CSS min-height values. The source does not change chat behavior, navigation, design tokens or extension permissions.

`client/tests/ui-qa-touch-079.test.mjs` characterizes transient 0px layout, detached elements, valid sizes and genuinely undersized 30px rows. These tests do not substitute for real Chromium UI acceptance.
