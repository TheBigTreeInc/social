= Tavi 0.3.122 — build-derived About and updater version
:revdate: 2026-11-05

== Evidence

The actual 0.3.121 source ZIP has Tauri `client/src-tauri/tauri.conf.json`, Cargo and `client/package.json` at 0.3.121, but `client/src/main.js` embeds `const CLIENT_VERSION='0.3.117';`. This value feeds the About view and the stable-release comparison. Thus an operator may launch the newest build yet see an older About version. The separate 0.3.117 ZipRunner stamp mismatch from 2026-10-25 was an older ZIP, not proof of current 0.3.121 import failure.

== Repair

* `client/vite.config.mjs` reads the single client package version and defines `__TAVI_CLIENT_VERSION__` for Vite build and dev.
* `client/src/main.js` uses the injected value, not a source-maintained literal.
* Regression checks enforce the Vite binding and equality of client package, root package, Tauri, Cargo, ZipRunner post-update stamp, and workboard version.
* No LoopRD service code, database migration, private config, release channel, updater backend, registration, game authority, or immutable TaviX package changes. Server descriptor remains 0.3.121, as the current source change is client-only.
