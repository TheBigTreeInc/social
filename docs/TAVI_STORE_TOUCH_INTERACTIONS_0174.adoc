= Tavi Store 0.3.174: viewport-aware discovery and install interactions
:revnumber: 0.3.174
:revdate: 2026-11-12
:status: source candidate; native Windows/Android QA and operator acceptance pending

== Objective

Make the unified Tavi Store feel native in the narrow Windows client, on Android phones, and on tablets without altering TaviX/Assets trust boundaries. Tavi remains a messenger first; chat navigation is always host-owned. This pass changes host-owned Store presentation only.

== Behavior

* Top-right manual refresh icon is removed. From the top of the Store listing, drag downward beyond 72 CSS pixels and release to refresh both TaviX and Assets catalogs. A visible pull/release/refresh state appears only during the gesture. Mouse, pen and touch are supported; horizontal gestures, active scrolling, and presses on controls or cards do not trigger a refresh. Refresh never reloads the Tavi shell or signs the user out. An unobtrusive `Refresh catalog` action remains at the bottom for keyboard and desktop users.
* The Store profile/avatar control has no heavy border/shadow, retains a 44px-equivalent hit target and visible keyboard focus. It continues opening the personal library, not a separate account authentication flow.
* Four categories use a 4-column adaptive layout so Discover, Apps, Games and Assets fit the 355px Windows viewport without horizontal clipping. Wider viewports use regular chips.
* Each app/game's icon, name and status form a single accessible details target. Each installed/eligible app has a separate Open, Enable, Install or Update action, chosen from the existing reviewed-app state. Unavailable and unverified apps have no privileged direct action. Direct install still requires the existing TaviX publisher/permission approval dialog.
* Asset icon/description opens the pack detail page. Only pinned, trusted, free, locally installable packs show a direct Install action, which opens the existing host-owned consent dialogue. Installed packs show Installed. Remote entries with no verified package/price have no purchase or installation action.
* The main Store does not charge Gold; no paid checkout is introduced. All install/ownership/permission checks remain with TaviX/Tavi Assets and LoopRD.

== Host and SDK ownership

No TaviX manifest schema, SDK import, looprd.yaml service, Tavi Assets endpoint, or Wallet implementation changes. The Store alone coordinates catalog refresh and opens existing controlled installation flows. The visual change is not a reason to expand TaviX window privileges.
