* `client/src/main.js` marks the host with `data-touch=true` when touch hardware is detected using `navigator.maxTouchPoints` or `any-pointer: coarse`.
* `client/src/ui/design-tokens.css` applies 44px minimum height for buddy, roster section and classic menu controls on touch hosts. Mouse-only compact Windows remains dense; a WebView does not need to report pointer-coarse to receive accessible touch targets.
* `client/tests/ui-qa-contract-078.test.mjs` protects both the consent sequence and the touch style contract.
* Twenty ZipRunner post-update definitions remain; no LoopRD schema change, credential change, or host/extension isolation change.
