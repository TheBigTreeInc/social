# Tavi 0.3.92 — Android Back / vector navigation handoff

**Source target:** existing `looprd-social` ZipRunner project, installed candidate 0.3.91.

## Purpose

Android's Back gesture and three-button Back used to close Tavi because its internal UI panels do not use WebView history. Tavi now registers Tauri's Android native `onBackButtonPress` listener (available in Tauri 2.9+) and routes it through the same host-owned `back` action as its visible navigation buttons. A fresh Android build is required; updating the web page alone will not correct an old APK.

## Back policy

- Modal extension install approval, Life launch approval, and diagnostics overlay close first.
- Message conversation -> Messages contact roster -> Home; repeated Back at Home does **not** exit or sign out.
- Settings, Games, portrait, companion, app launcher, App Store and other host utilities -> Home.
- Bundled Wallet/Companion -> Home; other installed extensions -> App Store. Sandboxed publishers cannot intercept the host-owned Back control or obtain Social credentials.
- At sign-in, account form -> server selection. At server selection, no implicit app exit.
- Editing with a visible soft keyboard dismisses keyboard before navigating. Reopening the same conversation retains the draft.

## Glyphs

Core navigation, message send, notifications, home, settings, and app toolbar icons use explicit inline SVG assets generated by `client/src/launcher.js`. No downloadable font, private font asset, network request, or external icon pack. The same core glyphs work with Android, Windows WebView2, and browser, inherited from CSS theme colors. Buttons keep visible labels/accessible names and touch target dimensions.

## Files

- `client/src/ui/navigation-policy.js`: pure predictable Back policy, keyboard check.
- `client/src/main.js`: Android OS Back registration and host action, UI labels and SVG glyph usage; draft preservation.
- `client/src/launcher.js`: fixed SVG glyph catalog reused by host chrome.
- `client/src/ui/shell.js`, `client/src/style.css`: accessible Back buttons and vector icon sizing.
- `client/tests/android-back-navigation-092.test.mjs`: regression suite.
- Tauri API/CLI minimum `2.9+` (native Android back event first appeared in API 2.9.0).
